# 歌伊 newGeYi v2.9.18

模块化 OlivOS 角色扮演 AI 聊天插件，包含多渠道模型调用、关系阶段、长期记忆、世界书与 Web 调试面板。

## 安装

将 `newGeYi` 目录放入 OlivOS 的 `plugin/app/`。首次运行前，复制 `config.example.json` 为 `config.json`，填写模型渠道及必要的管理账号。运行配置、数据库和生成数据仅保存在本地，不要提交到版本库。

插件面向 Python 3.11；模型接口使用 OpenAI 或 Anthropic 兼容 API。安装依赖以宿主 OlivOS 环境为准。

## 配置

- `api_endpoint`、`api_key`、`fast_model`：单渠道配置。
- `providers`：多渠道路由。每个渠道配置名称、端点、模型、凭据与优先级；凭据可由环境变量提供。
- `owner_ids`：管理账号列表。示例配置默认为空，请在本地设置。
- `private_enabled`、`memory_enabled`、`worldbook_enabled`、`galgame_enabled`：按需启用相应功能。

完整配置默认值见 `config.py`；本地密钥只放入 `config.json` 或环境变量。

## 功能

- 被动回复、主动聊天、图片理解及可选表情素材。
- 多渠道按优先级路由、故障转移、健康探测、熔断冷却与手动切换。
- 可选私聊关系阶段、好感度与阶段化世界书内容。
- 用户事实、印象与对话摘要组成的长期记忆，支持查看和删除。
- Web 调试面板用于检查会话、记忆、调用统计与运行状态。
- 本地 SQLite 状态存储；用户数据目录与插件包资源分离。

各功能默认值以 `config.example.json` 为准。关系系统及记忆功能涉及持久化用户数据，启用前请先核对本地配置与数据保留需求。

## 测试

在项目目录运行离线测试套件：

```powershell
python tools/run_webui_tests.py
```

该入口使用临时隔离状态目录，并在缺少 `requests` 时提供离线测试桩。若依赖已安装且仓库目录名为 `newGeYi`，也可从其上一级运行 `python -m unittest discover -s newGeYi/tests -v`。测试不需要真实模型密钥。
