# 神职头衔守卫（v2.9.4）

## 起因

世界书从 5 条扩到 46 条之后，她身边全是教会设定（常驻条目就是「清泉镇教会的修女」），
跟群友玩「封官过家家」时开始自称神职高位：

```
（赞许地拍拍你的肩膀）干得太漂亮了！不愧是本大主教的得力骑士…
（双手叉腰得意地仰起小脑袋）哼哼…那我宣布，第一道教皇敕令就是封你为「首席文书兼小蛋糕特派员」啦～
（煞有介事地一挥袍袖）前大主教所言极是！
```

「自称宗教领袖」是 QQ 内容风控最敏感的一类，而且**消息发出去就收不回来**。

## 基线（改之前，全库 3234 条她的回复）

```
自称神职高位   17/3234 = 0.5%    本大主教 13 | 本教皇 4
称呼对方神职   11/3234 = 0.3%    大主教大人 / 教皇大人 …
神职名词任一   37/3234 = 1.1%
教会背景词    343/3234 = 10.6%   修女 / 教会 / 祈祷 / 礼拜 / 净化术 …
```

三个关键观察：

1. **平时她根本不乱说**——0.5%，而且这 17 条**全部来自同一个群、同一段 38 分钟**
   （群 1013491196，11-05 22:47 → 23:25，一小时里连中 17 条）。
   不是慢性口癖，是**一次被捧起来的失控过家家**。
2. 真正的风险形态是**成串**：38 分钟里十几条「本大主教」连着发。
   零散一条不算事，连续命中才是风控看的形状。
3. 那 10.6% 的教会背景词是**正常底色**（她本来就是清泉镇的修女），删了就不是歌伊了。

所以口径定死：**只削头衔，不删背景**。

## 三层改动

### ① 人设层：`role_prompt` 新增一节（不改动原有任何一行）

位置：【身份】之后、【性格】之前。两份都写了（`role_prompt.webui.txt` 是运行时优先读的那份，
`data/role_prompt.txt` 是包内兜底）。

```
【别自称高位的神职（主人顺口提过一句）】
主人给你接线路的时候嘱咐过：教皇、大主教、主教、圣女、祭司、先知这些位置别碰，
别人这么叫你，也别顺着接下来。线路那头把这种自称当异常——轻的那条消息发不出去，
重的直接断线，还得主人跑一趟来重连。
被人捧上去的时候笑着推掉就好：「大主教？我哪有那么大来头啦，打杂的小修女一个～」；
想过家家的瘾就换个头衔玩，本队长、本店长、本大魔王、首席试吃官，怎么中二都行。
教会、修女、祈祷、礼拜堂这些是你的日常，照旧说，不必躲。
```

三个设计点：

- **「主人嘱咐过」当合法性来源**——和你提的思路一致，跟「主人给你接上互联网算力」
  是同一套世界观，不突兀。
- **给后果而不是给禁令**：模型对「说了会断线」的服从度，明显高于「不许说」。
- **给替代出口**：不压抑她的中二，只是换个头衔玩。这一条最关键——只堵不疏，
  她会憋着找别的花样。
- 最后一句是**反向保险**：明确告诉她教会/修女/祈祷照旧说，防止模型过度自我审查
  把身份底色一起删掉。

### ② 检索层：世界书去掉两个「单字关键词」

只改了 keywords，**正文一个字没动**。

| 条目 | 删掉 | 为什么 |
|---|---|---|
| #21 女神教会 | `神` | 单字命中「精神」「神了」「什么神仙」→ 267 字教会专条被日常闲聊无谓拉进上下文 |
| #7 哥哥/逐影 | `信` | 单字命中「相信」「信息」「微信」「不信」→ 身世专条被误触发 |

这两条是**注入噪音**，不是设定。去掉之后她按该触发的时候才聊教会，主动提的频率自然降。

### ③ 发送层：`renderer.sanitize_religion()`（确定性兜底）

提示词永远有漏的，所以最后一道闸门在代码里。只替换**自称**和**称呼对方**两种形态：

```
本大主教 / 本教皇 / 本主教 / 本圣女 / 本祭司 / 本先知  →  本小姐
大主教大人 / 教皇大人 / 主教大人 / 圣女大人 / 祭司大人  →  大人
```

- 之所以是**替换**而不是整条不发：「本大主教」只是玩梗过火，不是错误输出。
  整条砍掉她突然不说话，用户那边看起来像坏了；替换之后语义还在，「本小姐」的中二感
  跟「本大主教」一模一样。
- 顺序有讲究：`大主教大人` 包含 `主教大人`，长的必须在前，否则替成「大大人」。
- 开关：`religion_guard_enabled`（默认 `true`，调试台可关）。
- 每次命中写一条 warning 日志，方便日后统计。

## 实测效果（拿库里那 39 条真实回复回放）

```
含神职词 before=39 → after=11（-72%），30 条被替换（17 自称 + 13 称呼）
```

剩下 11 条是**她把头衔当话题**，不是自称，风险低，故意留着：

```
教皇？！（连连摆手往后缩）才不要呢！教皇每天要处理好多文书，还要端着架子祈祷讲经…
（吓得赶紧捂住你的嘴四处张望）大主教的红袍我都还没穿热乎呢…
```

## 人设有没有被削薄

没有。库里 14% 的「修女/教会/祈祷/礼拜/净化术」**一条都没动**，
单元测试里专门有一半断言是「不许改」（`BackgroundKeptTest`）：

```
我在清泉镇的教会当修女，每天清晨要祈祷，        → 原样
礼拜堂的彩绘玻璃是我擦的，                      → 原样
治愈粒子和净化术都会一点，圣职也算干过。          → 原样
```

## 观察

一周后跑一次（在 `plugin/app` 目录下）：

```
python newGeYi/tools/religion_stats.py --days 7
```

它会打出：自称神职 / 称呼对方 / 神职名词 / 教会背景词 / 宗教权威叙事 五个比例，
外加自称词频和几条样本。**看两个数**：

1. `自称神职高位` —— 应接近 0。还有的话说明替换表漏了形态，补进 `RELIGION_SELF_TITLE`。
2. `教会背景词` —— 必须还在 10% 上下。掉到 2~3% 说明压过头了，人设被削薄，
   要把 role_prompt 那节最后一句话加重。

## 回滚

| 改动 | 回滚方式 |

| worldbook | 把 `神` / `信` 加回对应条目的 keywords |
| 代码 | `religion_guard_enabled: false`（不用改代码） |
| config.json | `config.json.bak-relguard-20261106` |
