# 自定义称呼：歌伊怎么叫你（2026-11-09）

## 0. 一句话

每个用户可以给歌伊一个**自己的称呼**（全局一个、按 QQ 号存）；设过之后，提示词标签、
记忆提炼、@ 替换、记忆导出里看到的都是这个名字，而不是 QQ 昵称。

```
叫我 小明        # 设置
我的称呼         # 查看（也可以只发「叫我」）
称呼重置         # 清除，回到 QQ 昵称
称呼列表         # 骰主：列出所有设过的人
称呼重置 <QQ>    # 骰主：帮某人清掉
```

## 1. 为什么

QQ 昵称经常是 `AAA平板批发商`、`.mrrp`、一串颜文字。提示词的发言人是 `昵称(QQ号)：内容`，
她照着念出来既别扭，模型也容易把昵称当成"人设"的一部分（昵称里的梗会被当事实）。
自定义称呼让"怎么叫"变成用户的显式选择。

## 2. 设计口径（已确认）

- **全局一个**：不按群区分——在哪个群、私聊里，都叫这个名字；
- **本人设置**：任何人都能改自己的；骰主不能代设，只能 `称呼重置 <QQ>` 帮他清；
- **存 `settings` 的 `alias:<QQ号>`**：不新增表、不迁移，`settings_with_prefix` 直接可列；
- **空的 = 没设过**（写空串而不是删行，与 `mempriv:` 一致；列表会跳过空值）。

## 3. 生效链路（一处注入，下游全跟）

`Runtime.handle_message()` 在构造 `IncomingMessage` 时把 `sender_name` 换成称呼：

```
事件 → sender_name = aliases.display(store, sender_id, QQ昵称)
        ├─ prompt 标签：小明(123456789)：内容
        ├─ 记忆缓冲 memory_buffer.sender_name（提炼时看到的发言人）
        ├─ turns / live_context（群聊旁观窗口）
        ├─ 图片归属说明（"图1 是小明发的"）
        ├─ @ 替换（她写 @123456 时换成 @小明）
        └─ 记忆导出
```

另外 `PromptBuilder` 在 system 末尾追加一句（**只在设过时出现**）：

> （称呼：对方希望你叫他「小明」。就用这个名字称呼他；括号里的 QQ 号只是身份标记，不用念出来。）

为什么两个都要：标签只换了一个位置，而模型手里还有历史消息、印象卡、记忆事实里的旧昵称；
明说一句能压住"照抄旧昵称"。QQ 号**保留**在标签里——那是身份与防冒充的锚点，不能去掉。

## 4. 校验（`context/aliases.py::sanitize`）

| 规则 | 原因 |
|---|---|
| 1–12 字，连续空白折叠成一个空格 | 太长的称呼会把标签撑爆、也难叫 |
| 禁止 `[ ] 【 】 ( ) （ ） < > 《 》 { } 「 」 『 』 : ： @ \| " ' \`` | 标签是 `昵称(QQ号)：内容`，这些字符能伪造/断开发言人 |
| 禁止纯数字 | 会和 QQ 号混在一起 |
| 禁止保留词：`歌伊/主人/骰主/系统/管理员/官方/所有人/全体成员/你/我/他/她/对方/用户/AI` | 这些直接对应"谁在说话、谁能指挥她" |
| 禁止包含 `歌伊` | 会让她把自己和对方搞混 |

**指令侧防误伤**：`叫我` 必须带分隔符（空格 / `：` / `:`）才当指令——
`叫我起床`、`叫我一声` 这类正常说话继续走聊天（有测试钉着）。

## 5. 隐私

`忘了我` 会连称呼一起清掉（回复里会说明）。称呼是个人数据，不属于"配置"。

## 7. 验证

`tests/test_alias.py`（23 条）：

- 校验：合法名、空白折叠、超长、空、标签结构字符、纯数字、保留词、含"歌伊"；
- 存储：默认空、设置/读取/清除、`listing()` 跳过空值、按 QQ 号隔离；
- 运行时：无称呼时保持 QQ 昵称；设了之后 `handle_message` 的 `sender_name`、
  记忆缓冲里的 `sender_name` 都变成称呼；prompt 里同时出现标签与新称呼说明；
- 指令：设置/查看/重置、非法被拒且不落库、`叫我起床` 不被吃掉、全角冒号可用、
  骰主列表与代清、非骰主被拒、`忘了我` 清称呼。

全量回归：`tools/run_webui_tests.py`。

## 8. 已知限制

- **历史消息不回溯**：已入库的 `turns` / `memory_buffer` 行保留当时的昵称，改称呼后只影响新消息；
  旧消息在提示词里仍按 `旧昵称(QQ号)` 出现，属预期（那份记录本来就叫那个名字）。
- **记忆正文可能带旧名**：模型写进事实/印象里的名字不会自动改写。要清理用「忘了我」。
- **群聊面板看不到**：`session_get.state.alias` 只对私聊有意义（群聊会话不属于某一个人）。
