# v2.10.1 发布说明

## 群聊与私聊

- 群管理员可用 `本群其他AI 添加 <QQ> <昵称>` 管理机器人名单，另有删除、列表和清空子命令。
- `ai过滤 高` 屏蔽名单中的发言并断开回复里的名单昵称。`低` 按账号和昵称各自限流。`关` 关闭过滤并保留名单。
- `private_active_enabled` 默认关闭。启用后，插件会从当前私聊已记录的共同经历或未完成约定中寻找开场线索，并按安静时段、静默时间和每日上限控制发送。

## 剧情与记忆

- 群聊篇章由群管理员切换。私聊篇章由对话用户控制。两个会话各自保存剧情模式与当前篇章。
- 记忆召回继续遵守会话与篇章范围，最近约定及共同经历可以在无关键词命中时召回。
- 阶段提升和关系事件的提示只在回复成功发出后消费。关系评审读取本轮输入之前的用户消息。
- 世界书人物条目可设置 `pronouns`（如 `["她"]`），供代词追问匹配。
- 公开包附带最小角色提示和世界书示例。部署时，可在运行数据目录下提供自己的 `role_prompt.txt` 和 `worldbook.json`。

## 模型路由

- 显式声明调用类型的渠道优先于兼容通配渠道。
- `failover.lock_last_resort` 默认为 `true`。设为 `false` 后，兜底渠道接管请求，后台探测继续检查高优先级渠道，恢复后自动切回。
- 在本地配置或环境变量中提供服务地址、模型和凭据。

## 离线测试

在目录名为 `newGeYi` 的项目副本中运行 `python tools/run_webui_tests.py`，测试使用独立的临时数据目录。
