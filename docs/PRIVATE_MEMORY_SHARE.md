# 私聊的「群聊记忆共享」改成会话级选择（2026-11-09）

## 0. 一句话

`memory_private_enabled` 从「全体私聊的总闸」降级为**默认值**；每个私聊可以用
`群聊记忆开 / 群聊记忆关 / 群聊记忆默认` 自己决定要不要把群里的记忆带进来。

## 1. 起因

骰主反馈：「因为私信同步群聊记忆，所以会有私信无法清理群聊记忆的问题」。

查下来是两件事叠在一起：

1. **只有全局开关**。`memory_private_enabled` 一票决定所有人的私聊：想让某一个私聊
   不被群聊记忆影响，只能改全局；一改就是所有私聊一起变。
2. **「忘了我」清不干净群聊那一份**。`purge_user_facts()` 只删「当前会话 + `global`」，
   用户在私聊里说「忘了我」，**群聊会话里的那些事实仍然存在**；而私聊又在召回它们，
   于是表现成"说了忘记，她照样提"。

会话级开关解决第 1 条；第 2 条现在至少会**说清楚**（见 §4）。

## 2. 判定顺序

私聊读群聊记忆的条件，从高到低：

```
会话自己的选择（settings: mempriv:<session_key> = '1' / '0'）
  └─ 没设过 → memory_private_enabled（默认值）
       └─ 仍要过关系阶段门：galgame_cross_memory_min_stage（relation.cross）
```

- **群聊那一侧不提供会话级开关**：那个群要不要翻私聊，统一由 `memory_private_to_group`
  决定。理由是群聊是公共场合，不该由某个人临时决定"这个群可以翻我的私聊"。
- 显式「开」**也要过关系阶段门**：否则一个陌生人刚私聊就能把群里的你摸得一清二楚。
  阶段不够时状态里会写明原因；将 `galgame_cross_memory_min_stage` 设为 `0` 可关闭阶段门槛。
- 关闭共享 = 走数据库里既有的「私聊隔离」分支：**只查这个私聊会话自己的事实**，
  不查 `global`、不查任何群聊会话，也不召回群聊侧印象。这是 v2.8.19 隔离模式的老行为，
  没有新增"半开"档。
- 覆盖键是**完整会话键**（`bot_hash:platform:sdk:private:-:<QQ>`），和 `rest:`、
  `group_passive:` 等设置一致。代价：机器人账号被重加、`bot_hash` 变了以后，
  用户需要重新设一次（单机器人部署下不会遇到）。

## 3. 指令

| 指令 | 谁能用 | 作用 |
|---|---|---|
| `群聊记忆`（`群聊记忆状态`） | 任何人（私聊） | 看当前生效值 + 来源（你设的 / 默认）；阶段门挡住时说明原因 |
| `群聊记忆开` / `群聊记忆关` | 任何人（私聊） | 写入本会话的选择，立即生效（不用重载） |
| `群聊记忆默认`（`群聊记忆跟随默认`） | 任何人（私聊） | 清除本会话的选择，回到默认 |
| `群聊记忆列表` | 骰主 | 列出所有单独设置过的私聊（QQ + 开/关），没设过的跟随默认 |
| `群聊记忆重置 <QQ>` / `群聊记忆重置 全部` | 骰主 | 清除某个人 / 全部会话的选择 |

- 在群里发这些指令一律回一句「要私聊里单独设置」，不会写入。
- `群聊记忆重置`（不带参数）在私聊里等于「重置我自己」，对所有人都一致，
  避免"主人和非主人敲同一条命令得到两种结果"。

## 4. 「忘了我」现在会说明边界

`忘了我` 的行为没变（清当前会话 + `global` 的事实、全部 scope 的印象、关系数据与流水），
但如果这个私聊**正开着群聊记忆**，回复会补一句：

> （这个私聊还开着「群聊记忆」，群里说过的事我仍会想起来；发「群聊记忆关」可以关掉）

这样至少不会让人误以为"已经清干净了"。**如果你希望「忘了我」连群聊会话里的事实一起清**，
那是另一个决定（等于让用户在私聊里删掉别的群上下文），需要单独拍板——现在没做。

## 5. 落点

| 位置 | 改动 |
|---|---|
| `memory/repository.py` | `SHARE_OVERRIDE_PREFIX='mempriv:'`；`share_override()/set_share_override()/share_status()`；`cross_scope_enabled(..., override=None)`；`recall()` 里私聊带 override |
| `routing/commands.py` | 5 条指令 + 骰主 2 条；`忘了我` 补提示；「我的记忆」与注入用同一套 override |
| `panel.py` | `session_get.state` 增加 `group_memory_share`（None/True/False）与 `group_memory_default` |
| `config.py` | `memory_private_enabled` 的注释改成"默认值"语义 |

没有新增配置键，也没有改数据库表结构。

## 6. 验证

`tests/test_private_memory_share.py`（18 条）：

- 纯函数：默认跟随、会话覆盖双向、**群聊侧不受 override 影响**、阶段门优先于显式开；
- 存储：写入 '1'/'0'、清除回到"没设过"、`share_status` 的 source/stage_blocked；
- 召回：关掉后看不到群聊事实与群聊印象、自己私聊的事实仍在；默认关时会话可自行打开；
- 指令：状态文案、关→查→默认、群里拒绝、骰主列表/重置、非骰主被拒、`忘了我` 的提示。

全量回归：`tools/run_webui_tests.py`。

## 7. 回滚

- 只回 `memory/repository.py` + `routing/commands.py` + `panel.py` 即可；
- 已经写进 `settings` 的 `mempriv:*` 键留着无害（旧代码不读）；如需彻底清掉：
  `DELETE FROM settings WHERE key LIKE 'mempriv:%'`。
