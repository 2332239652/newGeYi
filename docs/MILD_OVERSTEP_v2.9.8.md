# 温和扣分 + 轻微反应（v2.9.8）

## 数据先说

拉出全部 845 条评审流水，把扣分的 41 条逐条看了：

```
扣分发生时对方所处阶段：stage 0 → 40 条，stage 1 → 1 条    （41/41 全在陌生/熟人）
扣分记录的亲密等级：    L2 → 30 条，L3 → 4 条              （83% 是 L2）
各阶段允许上限：        stage 0 → L1，stage 1 → L1，stage 2 才放 L2
```

**结论：他们不是在做什么过分的事，只是在陌生阶段用了朋友间最普通的语气。**

```
歌伊很可爱嘛        → L2 → pushy -1
给歌伊比心🫰🏻      → L2 → pushy -1
歌伊suki！          → L2 → pushy -1
摸摸歌伊            → L2 → pushy -1
```

按 846 条算，L2+ 只占 12.9%，而这 109 条里有 30 条被扣，**命中率 28%**。
等于每个新用户第一句话就可能踩雷，而**他完全不知道**——阿P 连踩 17 次，
中间没有任何反馈，还在用同样的方式接近。

这就是要改的两件事：**扣得轻一点**，**并且让她有点反应**。

## 改法一：按「超前几档」分级扣分

`relationship/service.py::process_interaction`

```python
if level > allowed_advance(rel.stage):
    gap = level - allowed_advance(rel.stage)
    if gap <= galgame_mild_gap:          # 只超前一点 → 不扣分
        raw, tag = 0, 'overstep'
        note = 'mild_overstep ...'
    else:                                 # 超前两档以上 → 照旧扣
        raw = min(raw, -1)
        tag = 'flirt_early' if level >= 3 else 'pushy'
    self._mark_mild_overstep(session_key, now)   # 两种都记一笔，让她有反应
```

| 情形 | 以前 | 现在 |
|---|---|---|
| stage 0 说 L2（"你真可爱"） | **-1 pushy** | **0，轻微越界** |
| stage 0 说 L3（"做我老婆"） | -1 flirt_early | -1 flirt_early（不变） |
| spam 复读 / 真纠缠（评审直接判） | -1 | -1（不变） |

新键 `galgame_mild_gap`（默认 1，调试台可改 0~3）：设 0 就完全回到旧行为。

## 改法二：轻微反应（新增）

被轻微越界时记一笔，**下一轮**注入到她的 system 里（一次性、15 分钟内有效）：

```
【刚才那句有点太亲近了】
对方上一句说得比你们现在的关系更近一点。这一轮你有点被打扰到：
可以脸红、往后退半步、把话岔开，或者装作没听懂带过去。
别生气、别说教、也别把「我们现在只是……」挂在嘴边——轻轻挡一下就好，不记账。
```

几个设计取舍：

- **为什么是下一轮**：评审在回复**发出之后**才跑（不增加延迟），所以对越界的反应
  天然只能体现在下一句。这也更像真人——被人突然说"喜欢你"，你愣一下，下一句才调整过来。
- **一次性**：读完就清掉，不会连着三轮都在害羞。
- **15 分钟过期**：隔一小时才回消息，不该还记着上一条的仇。
- **只说「轻轻挡一下」**：明确禁止说教和"我们现在只是……"——那两句最容易把她演成审核员。
