# v2.9.20 发布说明

本版本包含两批审计修复，并保留既有公开仓库历史。发布源码采用独立示例配置，运行配置、数据库、日志、内部交接资料与部署备份均不进入发布树。

## 修复

- 旧库迁移日志初始化；遗忘操作清理归档，并用持久代次和原文水位阻断旧任务重新写入。
- 回复文本最终转义、合法动作占位及昵称隔离；跨插件观察器采用完整会话身份。
- 调度执行权由 Future 和代次维护，长请求保留唯一执行者，关闭后停止接收任务。
- 缓冲清理按会话计算并保留待消费记录；超长提炼原文持久化分片进度。完整结果验证后，结果、游标和进度同事务提交。
- 图片类型、MIME、大小和本地可信目录检查；网络逐跳校验地址并绑定已验证IP，保留原域名TLS校验。
- 发送接口接受后才记录成功副作用；异步语音成功回调更新事实。关系评审固定历史快照，模型调用移至状态锁外。
- 网关统一网络等待预算，后台豁免错误保留前台路由；持久化软恢复任务，手选与配置代次阻止旧任务覆盖状态。
- 语音增加全局及会话容量、排队有效期、重载与关闭管理。配置入口共享写锁，面板版本检查与提交串行，临时文件独占创建。

## 使用变化与边界

`image_local_allowed_roots` 默认空列表，本地图片仅接受管理员明确配置的可信缓存目录。普通HTTP(S)图片逐跳校验；图片直连不继承环境代理或环境CA。输入检查验证魔数与MIME，未声称完整解码验证。兼容性用例覆盖 requests 2.31.0 / urllib3 1.26.20 与 requests 2.34.2 / urllib3 2.8.0，TLS使用受控参数和异常测试。

语音默认全局待处理8、单会话1、有效期30秒；显式语音请求同样受容量限制。发送成功表示发送API接受，没有统一平台回执保证。

网关超时后的底层请求可能仍在退出中，直到实际结束才释放全局槽。预算耗尽和过时代次请求跳过同步使用量写库，避免延长超时路径；正常结果本地SQLite或锁等待不属于网络等待硬实时保证。

配置锁覆盖本进程的受控写入口；外部编辑器仍需自行协调。缓冲保留待消费数据优先于软容量，因此提炼长期停顿时需监控存储增长。降级至不识别分片进度的旧版本前，应暂停提炼并处理未完成分片，保留当前数据库。
